# Làm diều hình thoi – Học liệu số STEM Toán 8

Tổ Khoa học tự nhiên – Trường THCS Võ Thị Sáu, Hải Phòng.
Tác giả: Ngô Thị Phương.

## Nội dung
- Chuẩn bị nguyên liệu (danh sách đánh dấu)
- Làm diều 8 bước: bản vẽ kỹ thuật động, việc cần làm, kiến thức Toán, thử thách nhỏ, 8 huy hiệu
- Tự thiết kế diều: đổi hai đường chéo, tự tính cạnh, diện tích, chu vi, khổ giấy
- Thả diều trên bầu trời ảo: chỉnh gió, đuôi, dây lèo; bảng gỡ rối
- Thử thách "Cổng bí ngô" 5 câu, lưu ý an toàn, tờ hướng dẫn tóm tắt

## Cách dùng
1. **Mở trực tiếp:** nháy đúp `index.html` (cần mạng để tải phông chữ; không có mạng trang vẫn chạy với phông dự phòng).
2. **Đưa lên GitHub + Vercel:**
   - Tạo repository mới trên GitHub, tải toàn bộ thư mục này lên.
   - Vào vercel.com → Add New → Project → chọn repository → Deploy (không cần chỉnh gì thêm).
3. **Nhúng vào Google Sites:** Chèn → Nhúng → dán đường link Vercel.

Tiến độ (nguyên liệu, huy hiệu) được lưu trên trình duyệt của từng học sinh.
